# Быстрый старт

[🇬🇧 English version](EN-Quick-Start)

**SG_Traders** — торговцы в стиле Tarkov для DayZ: 8 торговцев, уровни лояльности, покупка, скупка и бартер, торговые зоны. Вся настройка делается через JSON-файлы — код трогать не нужно.

Эта страница — минимум, чтобы мод заработал. Детали по каждому файлу — в остальных разделах вики.

---

## 1. Установка

1. Скопируйте папку `SG_Traders` в папку с модами вашего сервера.
2. Добавьте `SG_Traders` в список модов сервера (`-mod=` в батнике или `DZSALauncher` / `Server DZ mods`).
3. Мод нужен и на сервере, и у игроков: в нём есть серверная логика (`4_World`) и клиентский интерфейс (`5_Mission`, `gui/`). Если мод есть только на сервере — доска торговцев не откроется.
4. Запустите сервер.

Мод не требует никаких других модов. Если на сервере стоит `SG_Quest`, торговцы смогут открывать товары по выполненным заданиям; без него такие товары просто остаются закрытыми.

## 2. Где лежат конфиги

При **первом** запуске сервер сам создаёт папку с конфигами и записывает туда готовый набор из 8 торговцев:

```
$profile:SG_Traders\
├── SGTradersConfig.json        ← главный файл: зоны, админы, общие настройки
├── Traders\
│   ├── SGTrader_PRAPOR.json    ← каждый торговец в своём файле
│   ├── SGTrader_THERAPIST.json
│   ├── SGTrader_MECHANIC.json
│   ├── SGTrader_SKIER.json
│   ├── SGTrader_FENCE.json
│   ├── SGTrader_PEACEKEEPER.json
│   ├── SGTrader_JAEGER.json
│   └── SGTrader_REF.json
├── SGTradersState.json         ← таймеры завоза и «горячий товар» (не редактировать)
└── players\
    └── 76561198XXXXXXXXX.json  ← кошелёк, оборот, репутация игрока (не редактировать)
```

`$profile:` — это папка профиля сервера:

| Система | Путь |
|---|---|
| Windows | `<папка DayZServer>\ServerProfile\SG_Traders\` |
| Linux | папка из аргумента `-profiles=` (по умолчанию `~/.local/share/dayz/`), внутри `SG_Traders/` |

**Редактировать руками нужно только `SGTradersConfig.json` и файлы из `Traders\`.** Остальные два сервер ведёт сам.

## 3. Четыре правила, которые сэкономят вам вечер

1. **Останавливайте сервер перед правкой конфигов.** Конфиг читается один раз при старте сервера — правки подхватываются только после рестарта.
2. **Не правьте конфиги на работающем сервере.** Любое действие в админ-панели перезаписывает *все* файлы конфигов тем, что сейчас в памяти сервера. Ваши ручные правки, сделанные «на горячую», будут стёрты.
3. **Делайте копию папки `SG_Traders` перед правками.** Если в JSON будет ошибка, сервер скажет об этом в лог и продолжит работать со старыми/дефолтными значениями.
4. **Класснеймы пишутся точно.** Опечатка в `ClassName` не уронит сервер — торговец просто потеряет этот товар, а в лог уйдёт строка `WARNING: ... is not a valid item classname — removed`.

## 4. Минимальная настройка, без которой мод «не работает»

Чаще всего после установки жалуются на одно: **доска не открывается**. Причина почти всегда в торговых зонах — по умолчанию создаётся одна зона с координатами из примера, и там, скорее всего, никого нет.

Откройте `SGTradersConfig.json` и впишите свои координаты:

```json
"TradeZones": [
    {
        "Position": [ 7500.0, 0.0, 5200.0 ],
        "Radius": 50.0
    }
]
```

* `Position` — `[X, Y, Z]` из DayZ. `X` и `Z` — координаты на карте, `Y` — высота (обычно пишут `0`, проверка идёт по дистанции в 3D, так что небольшая ошибка по высоте не мешает).
* `Radius` — радиус зоны в метрах. `50` — комфортное значение для базы торговца.

Координаты удобно брать так: включите в игре карту с координатами, либо возьмите их из любого мода-телепорта / из `[X, Z]` в названии точки на карте (в DayZ координаты карты умножаются на 100: клетка `075, 052` → примерно `7500, 5200`).

Зон может быть сколько угодно — добавьте несколько объектов в массив.

## 5. Как игрок открывает доску

* Игрок заходит в торговую зону → у него появляется подсказка на экране.
* Нажимает **F8** (действие `UASGTradersOpen`, переназначается в настройках управления DayZ, раздел `SG_Traders`).
* Сервер **заново проверяет**, стоит ли игрок в зоне. Обойти это клиентским модом нельзя.

## 6. Откуда у игроков деньги

Стартовый кошелёк — **0**. Деньги появляются только двумя путями:

1. Игрок **продаёт** вещи торговцам.
2. Админ выдаёт деньги через **админ-панель** (раздел «Кошелёк»).

Валют две: рубли (`RUB`) и доллары (`USD`). Доллары принимает только Миротворец (`PEACEKEEPER`) — остальные торгуют за рубли.

## 7. Как проверить, что всё загрузилось

Включите отладочный лог в `SGTradersConfig.json`:

```json
"DebugLogging": true
```

и посмотрите в лог сервера строки с пометкой `[SG_Traders]`. На старте вы должны увидеть примерно такое:

```
[SG_Traders] Config loaded from ...SGTradersConfig.json (8 trader files)
[SG_Traders] Loaded 8 traders, 1 trade zones.
```

Если вместо этого видите `WARNING` — в таблице ошибок на странице [Админка и решение проблем](RU-Админка-и-решение-проблемы) есть расшифровка каждой строки.
