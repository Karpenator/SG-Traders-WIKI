# Товары и бартеры

[🇬🇧 English version](EN-Items-And-Barters)

**Что это:** разделы `Items` и `Barters` в файле торговца. `Items` — то, что торговец продаёт за деньги. `Barters` — то, что он отдаёт в обмен на другие предметы.

---

## `Items` — что торговец продаёт

Одна запись = одна строка в ассортименте:

```json
{
    "ClassName": "AKM",
    "Price": 25000,
    "LoyaltyLevel": 2,
    "MaxStock": 2,
    "QuestUnlock": "",
    "Category": ""
}
```

| Поле | Тип | По умолчанию | Что писать |
|---|---|---|---|
| `ClassName` | строка | `""` | Точный класснейм предмета из DayZ. С опечаткой строка молча удалится при загрузке. |
| `Price` | целое | `0` | Цена в валюте торговца **до** скидки за лояльность. |
| `LoyaltyLevel` | `1…4` | `1` | Минимальный уровень лояльности. `1` — доступно всем. |
| `MaxStock` | целое | `-1` | Сколько штук **один игрок** может купить за один цикл завоза. `-1` = без ограничений. |
| `QuestUnlock` | строка | `""` | ID задания из мода `SG_Quest`. Пусто — доступно всем. |
| `Category` | строка | `""` | В какую вкладку-фильтр положить товар. Пусто — определится автоматически. |

### ⚠️ `MaxStock` — это личный лимит игрока, а не склад торговца

Самая частая ошибка в понимании. `MaxStock: 2` означает:

> «Каждый игрок может купить 2 штуки, пока не пройдёт цикл завоза».

На 50 игроков это 100 проданных автоматов. Общего склада, который опустошают все вместе, в моде нет. Счётчик у каждого свой и обнуляется на завозе (`RestockMinutes`).

Как это выглядит у игрока:

| `MaxStock` | Что видит игрок |
|---|---|
| `-1` | `МНОГО` |
| `5` | `5` → `4` → … по мере покупок |
| `0` исчерпан | `НЕТ` и сообщение «Товар закончился. Дождитесь завоза.» |

### `Category` — вкладка в ассортименте

По умолчанию категория определяется по классу предмета. Иногда автоопределение даёт не то, что вы хотите (например, граната попадает в «Инструменты»). Тогда задайте вкладку вручную:

| Значение | Вкладка в интерфейсе (RU / EN) |
|---|---|
| `WEAPONS` | ОРЖ / WPN |
| `MAGAZINES` | МАГ / MAG |
| `AMMO` | ПТР / AMMO |
| `MEDICAL` | МЕД / MED |
| `FOOD` | ЕДА / FOOD |
| `CLOTHING` | ОДЕ / CLT |
| `VESTS` | ОДЕ / CLT (жилеты считаются одеждой) |
| `BACKPACKS` | ОДЕ / CLT (рюкзаки считаются одеждой) |
| `TOOLS` | ИНС / TOOL |
| `VALUABLES` | ЦЕН / VAL |
| `""` | определить автоматически |

Регистр не важен: `weapons`, `WEAPONS` и `Weapons` работают одинаково. Неизвестное значение игнорируется — предмет определится автоматически.

Вкладка **ЦЕН / VAL** — «свалка»: туда попадают ценности и всё, что вообще не удалось классифицировать. Так ни один товар не теряется из вида.

### `QuestUnlock` — товар за задание

```json
{ "ClassName": "NVGoggles", "Price": 45000, "LoyaltyLevel": 3, "MaxStock": 1, "QuestUnlock": "QUEST_NIGHT_HUNT", "Category": "" }
```

Пока игрок не выполнил задание `QUEST_NIGHT_HUNT`, строка для него невидима и не покупается.

**Важно:** сам `SG_Traders` про задания ничего не знает — он только спрашивает у мода `SG_Quest`, выполнено ли задание. Если `SG_Quest` на сервере не установлен, **любой** товар с непустым `QuestUnlock` будет закрыт для всех и навсегда. Не оставляйте заполненный `QuestUnlock`, если квестового мода нет.

## `Barters` — обмен предметами

Бартер — это товар без цены: вместо денег игрок отдаёт набор предметов.

```json
{
    "ClassName": "PSO1Optic",
    "LoyaltyLevel": 2,
    "MaxStock": 1,
    "QuestUnlock": "",
    "Category": "",
    "Cost": [
        { "ClassName": "CarBattery", "Quantity": 1 },
        { "ClassName": "SparkPlug",  "Quantity": 2 }
    ]
}
```

Поля те же, что у `Items`, кроме `Price` — вместо него массив `Cost`.

| Поле | Что это |
|---|---|
| `ClassName` | Что игрок **получает** |
| `Cost` | Список того, что игрок **отдаёт**: `ClassName` + `Quantity` |
| `LoyaltyLevel`, `MaxStock`, `QuestUnlock`, `Category` | Работают ровно как у обычных товаров |

Правила:

* Все предметы из `Cost` должны быть у игрока с собой (в руках, в карманах, в разгрузке или рюкзаке). Не хватает — сообщение «У вас нет нужных предметов для обмена».
* `Quantity` должен быть больше нуля. Строка с `Quantity: 0` или битым класснеймом удаляется.
* Если после проверки в бартере не осталось ни одной строки `Cost`, **весь бартер удаляется** с предупреждением в лог.
* Предметы из `Cost` не обязаны быть в ассортименте торговца — можно требовать что угодно.

### Сколько оборота даёт бартер

Бартер не имеет цены, но оборот (а значит и уровень лояльности) он начисляет. Считается так:

```
оборот = сумма( базовая цена каждого предмета из Cost × его количество )
```

Базовая цена берётся так же, как при скупке: цена из ассортимента этого торговца → иначе `SellValueOverrides` → иначе `DefaultSellValue` из главного конфига.

**Отсюда практический вывод:** если вы делаете бартер из предметов, которых нет у торговца и у которых нет `SellValueOverrides`, каждый из них засчитается в оборот как `DefaultSellValue` (по умолчанию 300). Хотите, чтобы бартер реально качал уровень, — добавьте для его ингредиентов `SellValueOverrides`.

## Рабочие примеры

### Простой товар, доступный всем и без ограничений

```json
{ "ClassName": "Rag", "Price": 25, "LoyaltyLevel": 1, "MaxStock": -1, "QuestUnlock": "", "Category": "MEDICAL" }
```

### Дефицит: одна штука на игрока за цикл, только для 4 уровня

```json
{ "ClassName": "NVGoggles", "Price": 45000, "LoyaltyLevel": 4, "MaxStock": 1, "QuestUnlock": "", "Category": "TOOLS" }
```

### Бартер «три доски и верёвка на арбалет»

```json
{
    "ClassName": "Crossbow",
    "LoyaltyLevel": 2,
    "MaxStock": 1,
    "QuestUnlock": "",
    "Category": "WEAPONS",
    "Cost": [
        { "ClassName": "HuntingKnife", "Quantity": 1 },
        { "ClassName": "Rope",         "Quantity": 2 },
        { "ClassName": "WoodenPlank",  "Quantity": 2 }
    ]
}
```

Это реальный бартер Рефа из стандартной поставки.

## Как быстро менять товары без правки JSON

У админов (`AdminSteamIds`) в доске есть кнопка **ADMIN**: там можно менять цену, уровень, лимит, добавлять и удалять товары и бартеры, и **все правки сразу сохраняются в файлы `Traders\`**. Это удобнее, чем искать строку в файле на 800 товаров.

Подробно — [Админка и решение проблем](RU-Админка-и-решение-проблемы).

## Частые ошибки

| Симптом | Причина |
|---|---|
| Товара нет в списке, в логе `WARNING: ... offer 'X' is not a valid item classname — removed` | Опечатка в `ClassName`. Проверьте имя по вики DayZ или по `types.xml` вашей сборки. |
| Товар виден, но не покупается: «Ваш уровень лояльности слишком низок» | `LoyaltyLevel` выше уровня игрока у этого торговца |
| Товар виден, но не покупается: «Товар закончился» | Игрок выбрал свой `MaxStock` за этот цикл |
| Бартер пропал, в логе `barter ... has no cost lines — removed` | Все строки `Cost` оказались битыми (класснейм или `Quantity`) |
| Товар не у всех игроков | Заполнен `QuestUnlock`, а мода `SG_Quest` на сервере нет |
| Товар попал не в ту вкладку | Автоопределение категории. Задайте `Category` вручную |
