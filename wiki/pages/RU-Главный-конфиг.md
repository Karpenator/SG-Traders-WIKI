# Главный конфиг — `SGTradersConfig.json`

[🇬🇧 English version](EN-Main-Config)

**Что это:** один файл с общими настройками всей системы. Здесь живут торговые зоны, список админов, базовые цены и список торговцев. Сами товары тут **не** хранятся — они в отдельных файлах в папке `Traders\`.

Путь: `$profile:SG_Traders\SGTradersConfig.json`

---

## Как выглядит файл целиком

```json
{
    "DebugLogging": false,
    "DefaultSellValue": 300,
    "SellConditionFloor": 0.25,
    "LoyaltyDiscountStep": 0.05,
    "AdminSteamIds": [
        "76561198012345678"
    ],
    "TradeZones": [
        {
            "Position": [ 11802.33, 2.18, 3265.71 ],
            "Radius": 50.0
        }
    ],
    "TraderIds": [
        "PRAPOR",
        "THERAPIST",
        "MECHANIC",
        "SKIER",
        "FENCE",
        "PEACEKEEPER",
        "JAEGER",
        "REF"
    ]
}
```

> Файл создаёт сам сервер при первом запуске. Всегда начинайте правку от сгенерированного файла, а не от примера из вики — так вы не ошибётесь с форматом.

---

## Все поля по порядку

| Поле | Тип | По умолчанию | Что делает |
|---|---|---|---|
| `DebugLogging` | `true` / `false` | `false` | Печатает в лог сервера подробности каждой сделки: `[SG_Traders][DEBUG] Buy: ... bought AKM from PRAPOR for 9500`. Удобно на настройке, на бою лучше выключить. |
| `DefaultSellValue` | целое | `300` | **Цена-заглушка.** Сколько «стоит» предмет, если торговец его не продаёт и для него нет отдельной цены. От этой цифры считается цена скупки. |
| `SellConditionFloor` | дробное `0…1` | `0.25` | Какой процент цены получит полностью сломанный предмет. `0.25` = сломанная вещь продаётся за 25 % цены, новая — за 100 %. |
| `LoyaltyDiscountStep` | дробное | `0.05` | Скидка за каждый уровень лояльности выше первого. `0.05` = 5 % за уровень. `0` отключает скидки. |
| `AdminSteamIds` | список строк | `[]` | SteamID64 админов. У них в доске появляется кнопка **ADMIN**. Список никогда не уходит игрокам. |
| `TradeZones` | список зон | 1 пример зоны | Круги на карте, внутри которых открывается доска. |
| `TraderIds` | список строк | 8 шт. | Какие файлы торговцев загружать и в каком порядке показывать их в доске. |

## `TradeZones` — где можно торговать

```json
"TradeZones": [
    {
        "Position": [ 7500.0, 0.0, 5200.0 ],
        "Radius": 50.0
    },
    {
        "Position": [ 4300.0, 0.0, 6400.0 ],
        "Radius": 25.0
    }
]
```

* Проверка идёт по **обычной дистанции в 3D**, поэтому `Radius` должен покрывать и перепад высот. Если база торговцев на горе — берите радиус с запасом.
* Зон может быть любое количество. Игрок видит подсказку и может открыть доску, находясь **хотя бы в одной** из них.
* Если список пуст, сервер напишет в лог:
  `WARNING: No trade zones configured — the board cannot be opened anywhere.`

## `AdminSteamIds` — кто может всё

```json
"AdminSteamIds": [
    "76561198012343378",
    "76561198087184321"
]
```

## `LoyaltyDiscountStep` — как считается скидка

Формула покупки:

```
цена = округлить( Price × (1 − шаг × (уровень − 1)) )
```

Результат никогда не опускается ниже 50 % от `Price`, а сам шаг не может быть больше `0.15` — даже если вы впишете `0.5`, сервер возьмёт `0.15`.

Пример при `LoyaltyDiscountStep: 0.05` и `Price: 10000`:

| Уровень лояльности | Множитель | Итоговая цена |
|---|---|---|
| 1 | 1.00 | 10 000 |
| 2 | 0.95 | 9 500 |
| 3 | 0.90 | 9 000 |
| 4 | 0.85 | 8 500 |

Скидка действует **только на покупку** (`Price` и бартеры она не трогает) и считается отдельно для каждого торговца.

## `SellConditionFloor` и `DefaultSellValue` — коротко

Оба влияют только на то, **сколько торговец платит вам**. Полная формула и примеры — на странице [Скупка и лимиты](RU-Скупка-и-лимиты).

* `SellConditionFloor: 1.0` — состояние предмета вообще не влияет на цену.
* `SellConditionFloor: 0.0` — сломанная вещь не стоит ничего.
* `DefaultSellValue` поднимайте, если хотите, чтобы «мусор» (всё, чего нет в ассортименте) стоил дороже.

## `TraderIds` — порядок и состав торговцев

* Порядок в списке = порядок карточек в доске торговцев.
* Убрать торговца = удалить его ID из списка. Сам файл можно оставить на диске — он просто не загрузится.

Подробно, в том числе как добавить своего торговца — на странице [Файл торговца](RU-Файл-торговца).

## Частые ошибки

| Симптом | Причина |
|---|---|
| Доска не открывается нигде | Пустой `TradeZones` или зона не там, где стоит игрок |
| Правки не применяются | Сервер не перезапускали, либо правили на работающем сервере и их перезаписала админка |
| Сервер пишет `Config load failed, keeping defaults. Check the JSON syntax` | Ошибка синтаксиса JSON: лишняя запятая после последнего элемента, кавычки «ёлочки» вместо `"`, комментарий `//` |
| Кнопка ADMIN не появилась | SteamID указан не тот, или админ не перезашёл на сервер после правки |

JSON **не поддерживает комментарии** — не оставляйте `//` в файле, это самая частая причина отказа загрузки.
