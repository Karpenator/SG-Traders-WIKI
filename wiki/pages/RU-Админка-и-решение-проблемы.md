# Админка и решение проблем

[🇬🇧 English version](EN-Admin-And-Troubleshooting)

**Что это:** встроенная админ-панель внутри доски торговцев и справочник по сообщениям в логе сервера.

---

## Как открыть

1. Впишите свой SteamID64 в `AdminSteamIds` в `SGTradersConfig.json`.
2. Перезапустите сервер и зайдите на него (статус админа выдаётся при входе).
3. Откройте доску торговцев в торговой зоне (**F8**).
4. Нажмите кнопку **ADMIN**.

Не-админы кнопку просто не видят. Список админов игрокам никогда не передаётся — на клиент уходит только «да/нет».

---

## Что умеет панель

### Торговцы
Переключение между всеми торговцами из `TraderIds`. Панель всегда работает с одним выбранным.

### Пороги оборота
Поля для уровней II / III / IV: оборот и репутация. Плюс блок **«РЕП ЗА ОБОРОТ»** — включить/выключить и настроить интервал и шаг.

* Пороги автоматически выстраиваются по возрастанию: если вписать III меньше II, сервер поднимет III до `II + 1`.
* Репутация приводится к диапазону `0…9.99`.
* Дробную часть можно вводить через запятую или точку — сервер поймёт и то и то.
* Сохраняется в `LoyaltyThresholds`, `LoyaltyReputationThresholds`, `TurnoverReputation*`.

### Товары
Таблица всего ассортимента: предмет, цена, уровень, `MaxStock`, лимит скупки.

* Правка строки + **OK** — сохраняет изменения.
* **X** — удаляет товар.
* **ADD ITEM** — добавляет новый: откроется окно выбора с поиском по игровым предметам, не нужно помнить класснейм наизусть.
* Колонка «лимит скупки» показывает личный лимит предмета; если личного нет — общий `DefaultSellLimit`.

### Бартеры
Таблица бартеров. Формат цены обмена:

```
CarBattery:1;SparkPlug:2
```

то есть `Класснейм:Количество`, несколько позиций через **точку с запятой**. Символ `|` в стоимости использовать нельзя — панель его не примет.

* **+ NEW BARTER** — пустая строка для нового бартера.
* Класснейм, стоимость, уровень и `MaxStock` редактируются прямо в строке.

### Игроки онлайн
Список тех, кто сейчас на сервере: оборот, уровень и репутация **у выбранного торговца**, рубли и доллары.

| Действие | Что делает |
|---|---|
| Кнопки **1 / 2 / 3 / 4** | Ставит уровень лояльности: записывает оборот, равный порогу этого уровня, и поднимает репутацию до нужного минимума. Заработанное игроком никогда не понижается. |
| **РЕПУТАЦИЯ** + значение | Задаёт репутацию напрямую (`0…9.99`) |
| **КОШЕЛЁК** + `+` / `−` | Прибавляет или вычитает сумму в рублях или долларах |

Уровень нельзя поставить выше, чем позволяет количество порогов у этого торговца: при двух порогах максимум будет 3.

### Куда это сохраняется

**Каждое изменение конфигурации сразу пишется на диск** — в `SGTradersConfig.json` и в файл нужного торговца в `Traders\`. Все открытые доски у игроков обновляются мгновенно, рестарт не нужен.

⚠️ **Обратная сторона:** панель перезаписывает файлы тем, что сейчас в памяти сервера. Если вы правили конфиг руками, не останавливая сервер, — эти правки будут потеряны при первом же сохранении из админки. Порядок такой: остановили сервер → поправили файлы → запустили.

## Отладочный лог

`"DebugLogging": true` в `SGTradersConfig.json` включает подробные строки вида:

```
[SG_Traders][DEBUG] Buy: 76561198012345678 bought AKM from PRAPOR for 23750
[SG_Traders][DEBUG] Sell: 76561198012345678 sold 4x BearPelt to FENCE for 360
[SG_Traders][DEBUG] Restocked PRAPOR
[SG_Traders][DEBUG] Admin 76561198012345678 set thresholds of PRAPOR to 12000/45000/120000 rep 0.04/0.09/0.15 ...
```

Предупреждения (`WARNING`) печатаются всегда, независимо от этого флага.

Отдельно в коде есть константа `SGTR_TRACE_UI` (`scripts/3_Game/SGTradersConstants.c`, по умолчанию `true`) — она печатает цепочку открытия доски: нажатие клавиши → RPC → меню. Её стоит выставить в `false`, когда всё работает, иначе в логе будет много строк `DBG:`. Это изменение в коде, а не в конфиге — потребуется пересборка мода.

## Что означают строки в логе

Все строки начинаются с `[SG_Traders] `.

### При загрузке конфигурации

| Строка в логе | Что случилось | Что делать |
|---|---|---|
| `Config loaded from ... (8 trader files)` | Всё хорошо | — |
| `Loaded 8 traders, 1 trade zones.` | Конфиг применён | — |
| `Default config written to ... (8 trader files)` | Конфигов не было, создан стандартный набор | Нормально для первого запуска |
| `Legacy config migrated: traders split into $profile:SG_Traders\Traders\` | Старый единый файл разложен по торговцам | Нормально, сделано один раз |
| `Config load failed, keeping defaults. Check the JSON syntax of ...` | **Ошибка в JSON** | Проверьте синтаксис: лишняя запятая, «ёлочки» вместо `"`, комментарий `//` |
| `No traders could be loaded from ... — regenerating defaults` | Ни один торговец не загрузился, создан стандартный набор | Проверьте `TraderIds` и файлы в `Traders\` |
| `Trader file missing: ... — skipped` | ID есть в `TraderIds`, а файла нет | Проверьте имя файла: `SGTrader_<ID>.json` |
| `Trader file invalid: ... — skipped` | Файл не прочитался или пустой `Id` | Проверьте синтаксис JSON в этом файле |
| `Trader with empty or duplicated Id removed at index N` | Пустой или повторяющийся `Id` | `Id` должен быть уникальным |
| `Trader X: broken NameKey 'Y' replaced by '#STR_SGTR_trader_x'` | `NameKey` не начинался с `#` | Используйте ключ перевода, а не текст |

### При проверке содержимого

| Строка в логе | Что случилось | Что делать |
|---|---|---|
| `X: unknown currency 'Y', falling back to RUB.` | Валюта не `RUB` и не `USD` | Доступны только эти две |
| `X: offer 'Y' is not a valid item classname — removed.` | Опечатка в `ClassName` товара | Проверьте класснейм |
| `X: barter reward 'Y' is not a valid item classname — removed.` | Опечатка в награде бартера | Проверьте класснейм |
| `X: barter cost 'Y' invalid — cost line removed.` | Битая строка стоимости в бартере | Класснейм или `Quantity ≤ 0` |
| `X: barter Y has no cost lines — removed.` | После проверки в бартере не осталось стоимости | Добавьте хотя бы одну корректную строку `Cost` |
| `X: hot pool entry 'Y' is not a valid item classname — removed.` | Опечатка в `HotItemPool` | Проверьте класснейм |
| `X: invalid sell limit entry — removed.` | В `SellLimits` пустой `ClassName` или `MaxPerRestock ≤ 0` | Удалите запись, чтобы снять лимит |
| `X: negative TurnoverReputationInterval — progression disabled for this trader.` | Отрицательный интервал | Заменено на `0`, начисление выключено |
| `X: negative TurnoverReputationGain — progression disabled for this trader.` | Отрицательный шаг | Заменено на `0`, начисление выключено |

### В работе

| Строка в логе | Что случилось |
|---|---|
| `No trade zones configured — the board cannot be opened anywhere.` | Пустой `TradeZones` — доска не откроется нигде |
| `Restocked X` | У торговца прошёл цикл завоза |
| `Open request outside trade zone by ...` (только при `DebugLogging`) | Игрок пытался открыть доску вне зоны |

Ни одно из этих предупреждений **не останавливает сервер**: битая запись просто удаляется, и мод работает дальше без неё.

## Частые проблемы

### Доска не открывается

По порядку:

1. **Мод есть у игрока?** Мод клиент-серверный: без него на клиенте интерфейс не появится вообще.
2. **Игрок в зоне?** Проверьте координаты в `TradeZones` и радиус. Есть подсказка на экране — значит зона найдена.
3. **Список зон не пустой?** Ищите в логе `No trade zones configured`.
4. **Клавиша не занята?** `F8` может конфликтовать с другим модом. Переназначьте в настройках управления, раздел `SG_Traders`.
5. **Игрок жив?** Мёртвому доска не открывается.
6. **Открыто другое меню?** Пока открыт инвентарь или карта, доска не откроется.

### «Недостаточно средств», хотя деньги есть

Проверьте валюту: у Миротворца всё в **долларах**, у остальных в **рублях**. Кошелёк общий на сервер, но у каждой валюты свой баланс.

### Товар пропал после рестарта

Скорее всего в логе есть строка `is not a valid item classname — removed`. Класснейм не существует в вашей сборке (например, предмет из мода, которого нет на сервере).

### Правки не применяются

* Сервер не перезапускали — конфиг читается только при старте.
* Правки сделаны на работающем сервере и перезаписаны админ-панелью.
* Правится не тот файл: проверьте, что это `$profile:SG_Traders\...`, а не копия в папке мода.

### Игрок не может продать предмет

* Категории предмета нет в `SellCategories` торговца.
* Предмет **ЗАПОЛНЕН** — внутри что-то лежит.
* Лимит скупки выбран до следующего завоза.
* Предмет вообще не определяется ни в одну категорию (доски, брёвна) — такие не покупаются даже при `ALL`.

### Как полностью обнулить экономику

При выключенном сервере удалите папки и файлы:

```
$profile:SG_Traders\players\*        ← кошельки, оборот, репутация, лимиты
$profile:SG_Traders\SGTradersState.json  ← таймеры завоза и «горячий товар»
```

Конфиги (`SGTradersConfig.json` и `Traders\`) при этом не пострадают.

### Как вернуть стандартные настройки

При выключенном сервере удалите `SGTradersConfig.json` и папку `Traders\`. При следующем запуске сервер создаст их заново с восемью стандартными торговцами.
